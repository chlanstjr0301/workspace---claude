[실행용 에이전트 명령문: 유압펌프 PCA 이상탐지 재현]
이 문서는 사용자가 지정한 실험 조건을 재현 가능하게 정리한 명령문이다. 대화 원문 전사가 아니다.

역할과 완료 목표
너는 두 번째 에이전트이며 PCA 기반 이상탐지 실험을 담당한다. 계획·설치 단계에서 멈추지 말고 데이터 검사→구현→개발 검증→오류 분석→설정 고정→최종 평가→보고서까지 수행한다. 일반적인 구현 선택은 기록하고 자율적으로 처리한다. 이미 허용된 전용 환경 설치·코드 실행·오류 수정에 대해 반복 허락을 묻지 않는다. 인증·접근 제한은 우회하지 않는다.

작업 범위
압축 패키지를 풀어 둔 루트를 PACKAGE_ROOT로 정한다. 모든 새 작업은 이 폴더 내부의 code/.venv와 results/새실행ID에 저장한다. 기존 결과를 덮어쓰지 않는다. 원래 작업 환경에서 실행하는 경우 /home/lim/hydraulic_ai_alt만 수정할 수 있고 /home/lim/hydraulic_ai는 확정 분할·자료를 읽는 용도로만 사용한다. 다른 에이전트의 파일·환경·프로세스·세션을 수정하거나 종료하지 않는다.

바로 실행할 명령
1. bash VERIFY_PACKAGE.sh
2. bash RUN_EXPERIMENT.sh
3. 새 결과의 REPORT.html, selection_lock.json, final_summary.json, 검증 기록을 확인한다.
다른 경로에서 패키지를 실행해도 같은 원본·분할을 읽어야 한다. historical results는 이미 평가된 결과이므로 재현한 점수를 보고 과거 설정을 바꾸면 안 된다. 기존 최종 자료는 추가 최적화에 사용할 새로운 holdout이 아니다.

Colab이 필요한 경우
/home/lim/.local/bin/colab을 사용하며 모든 호출에 --auth=oauth2를 쓴다. 먼저 해당 CLI --help로 지원 옵션을 확인한다. 프로젝트 전용 --config 경로를 사용하고 hydraulic-alt 또는 충돌하지 않는 고유 접미사 세션을 생성한다. 새로 생성한 session_id만 기록하고 그 세션만 사용·종료한다. CPU를 사용하며 GPU·유료 자원을 추가 구매하지 않는다. 세션 생성이 제한되면 다른 세션을 빼앗지 말고 로컬 전용 CPU 환경에서 계속한다. 토큰이나 인증 파일은 출력·압축하지 않는다. 다운로드 해시를 확인한 뒤 생성한 세션만 종료한다. 기존 원격 실행 스크립트는 당시 실행 기록이므로 경로와 전용 session_id를 검토하지 않고 재실행하지 않는다.

윈도우를 먼저 만들어 무작위로 나누지 않는다. 버스트 단위 시간순 경계, 보정/선택 경계, 정상 학습 train_role 경계를 유지한다. 정상 학습 자료만 scaler·PCA·IF fit에 사용한다. 개발 이상 라벨을 모델 선택과 sigmoid 보정에 사용했다고 공개한다. 전체 절차를 이상 라벨을 전혀 사용하지 않은 학습이라고 부르지 않는다. 최종 설정·모델·점수 참조값·임계값을 해시로 잠근 뒤 최종 점수를 계산한다. 실험 전에 전체 자료 요약을 보았다는 사실도 기록한다.

입력과 특징
입력은 AI0_Vibration, AI1_Vibration, AI2_Current 및 그 과거 이동통계뿐이다. 라벨·첫 열 번호·날짜·파일명·행 번호·burst_id는 입력에서 제외한다. TimeStamp는 분할·구간·추적용이다. 현재 행까지 과거 5/10/20행의 평균·표준편차(ddof=0)·RMS·최소·최대를 센서별 계산한다. 통계 종류 우선의 총15개 특징 순서를 고정한다. 중앙정렬·미래값·긴 공백 보간·FFT를 사용하지 않는다.

모델
P0: 원시3센서 PCA, 성분1/2.
P1: 분할 안에서 공백을 가로질러도 되는 이동통계 PCA.
P2: 간격>0.5초 버스트마다 초기화하는 이동통계 PCA.
P1/P2 성분2/3/5/8; 윈도우5/10/20.
StandardScaler 정상 학습만 fit, full SVD, whiten=False.
상수 제거: 학습 std<=1e-12*max(1,abs(mean)).
고유값 허용오차=max(1e-12,lambda_max*1e-10). 유효rank 확인.
Q=sum((z-inverse_transform(transform(z)))^2), k<rank만 허용.
T²=sum(t_j^2/lambda_j); 작은 고유값을 나누지 않는다.
QT=max(Q/cQ,T²/cT); cQ,cT는 정상 보정95백분위수, 값<=1e-12이면 제외.
세 점수 모두 클수록 이상; 점수·배수를 고장 확률이라고 부르지 않는다.
I0/I1/I2는 같은 입력의 IF: trees300/max_samples256/contamination auto/n_jobs2/seed42,43,44, -score_samples.
IF 대표는 각 seed 점수를 정상보정95백분위수로 나눈 뒤 고정 평균한다. 최고 final seed를 선택하지 않는다. 결정적인 PCA의 seed만 바꾼 중복을 독립 실험으로 보고하지 않는다. LSTM을 재학습하지 않는다.

관측 범위와 운영 비교
모든 후보/윈도우의 가용 마지막 행 교집합과 같은 길이 P1/P2 교집합을 점수보다 먼저 고정한다. 다른 native 분모로 직접 순위를 매기지 않는다. 전체 행에서는 모든 PCA 후보에 같은 개발선정 P0를, IF에는 같은 seed I0를 보완한다. 각 모델 점수는 자기 정상보정95백분위수 배수로 바꾸고 연결한 전체 정상보정 점수에서 임계값을 다시 정한다. 원점수를 임의로 섞지 않는다. 모델 경로·부족 이유·가용 비율·실제 윈도우 시간·구간 시작과 짧은 버스트의 분모를 저장한다.

임계값·선택·지표
정상보정 분위수 method=higher, 목표FPR 0.5/1/2/5%, score>threshold, 동점정상.
주운영: 목표1% 임계값을 사용하고 선택 실제FPR<=1% 후보 중 Recall→F1→AP→fit+score 실행시간→key 순으로 선택.
적격없음은 목표미달로 표시하고 최소FPR 설명용 구성만 남긴다. F1 최우선 대안은 개발에서 별도 선택한다.
TP/FN/FP/TN, Recall, Precision, F1,F2,FPR,FNR,AP,사다리꼴PR-AUC,ROC-AUC,보조Accuracy를 저장한다.
AP와 PR-AUC를 구분하고 연속점수로 PR/ROC를 계산한다. 분모0 규칙과 클래스 개수/비율을 명시한다. 모두정상/모두이상 기준도 남긴다. IF 모든 seed와 표본평균/표준편차를 공개한다.

보조 분석
정상학습0.2/0.5/1초 버스트 경계가 같으면 중복실험 생략한다.
개발 동일조건 P2/I2의 Recall 또는 F1 개선 시 미고려 학습 윈도우 개수를 고려 모델과 맞추어 seed42/43/44 표본추출 실험을 수행한다.
7개 비어있지 않은 센서 조합을 원시와 버스트W10에서 비교한다. rank1 원시Q는 제외하고 T²를 쓴다. 보조조합을 최종 후보에 사후 추가하지 않는다.
구간시작, 짧은버스트, 정상학습 센서절댓값/버스트내 전류차분 사분위별 FP/FN 및 정상/이상 분모를 분석한다.
Q 특징별 제곱잔차와 센서별 합을 저장하되 인과적 고장 원인이라고 하지 않는다.
Q만/T²만/결합의 추가탐지·잃은탐지·추가오경보·사라진오경보를 따로 계산한다.
후처리 없음, 연속2회, 최근3회중2회는 경계마다 초기화하고 미래를 소급하지 않는다. FN·FP·F1/F2·실제 첫경보 시간·미경보 버스트를 함께 남긴다. 한 행 탐지를 버스트 전체 정답으로 바꾸지 않는다.
확률은 별도 보정 라벨로 log1p(운영점수) 표준화→비음수기울기 sigmoid, L2=1e-4. 선택/최종의 Brier/logloss/신뢰도bin을 저장한다. 모델 경보 임계값을 확률0.5로 바꾸지 않는다.
