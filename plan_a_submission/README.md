# Plan A 실행 패키지

Plan A의 초기 기준선·후보모델 실험 코드와 결과를 보관한다.

```powershell
pip install -r plan_a_submission/requirements.txt
python plan_a_submission/src/run_all.py
```

- 코드: `src/`
- 결과: `outputs/`
- 결과 해설: `docs/plan/plan A/RESULTS.md`
- 논문 초안: `papers/plan_a/`

새 실험은 Plan C 또는 Plan D 결과와 합치지 말고 이 폴더의 `outputs/`에만 기록한다.
