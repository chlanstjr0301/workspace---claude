## 1. Plan A 문항별 채점

### 1.1 데이터 이해 및 진단 (15점)

- **공식 요구**: 생산단위, 변수 의미, 시간·설비·제품 관계, 결측·중복·이상치·불균형, 전처리·검증전략
- **충족 증거**: gap-aware windowing(dt > 0.5 s, `data.py:37-41`), burst 구조(정상 599 / 이상 21), 측정 한계 선언표(FAR/h 분해능·탐지지연 하한·Event Recall 축퇴, `RESULTS.md:99-110`), AI2 세션 교란 진단(캐리어 비중 0.959 → 0.104), 정상 내부 운전변화 구간 발견(16,000–19,000행)
- **결손 증거**: 결측·중복 진단표 없음(중복 TimeStamp 1건 미언급), 변수 단위·센서 사양 없음, 불균형 비율(window 기준 10%)과 유효 사건 수 1의 관계 서술 약함, 분할 경계가 burst 내부를 지남(A-P2-02), 진동 채널의 세션 교란 미언급(COMMON-P1-03)
- **현재 점수**: **11** · 보수적 범위 9–12
- **핵심 감점 이유**: 체계적 진단표 부재, "물리적으로 불가능" 단정(A-P1-09)
- **수정 후 가능 점수**: 13
- **필요 작업**: 결측·중복·이상치·불균형 표 1장, 변수 정의표, 진동 교란 한계 1문단

### 1.2 AI 예측모델 개발 및 성능평가 (40점)

- **공식 요구**: 제조 이상 **확률** 예측 모델, 베이스라인 포함 2개 이상 비교(F1 등), 최종모델 선정근거, 동일 평가조건
- **충족 증거**: 8개 검출기 × 4개 특징집합 = 32개 후보를 동일 분할·동일 임계값 정책으로 비교(`model_comparison.csv`), 2층 베이스라인, burst 블록 부트스트랩 CI, 1·2위 비구분 정직 공개(ΔF1 CI [−0.022, +0.043]), 재계산 일치(F1 0.9282, AP 0.9743)
- **결손 증거**
  - 선정이 테스트 이상 라벨에 의존(A-P1-01). 블록 회전 시 순위 1 → 3 → 8 → 8
  - "FP 0"이 분할 하나에서만 성립, 다른 블록에서는 FP 1–32(A-P1-02)
  - "파라미터 0개" 사실 오류(A-P1-03)
  - 확률 출력 `anomaly_prob`이 정상 window의 65.5%에서 0.5를 넘고, Brier 0.402로 상수 예측(0.090)보다 나쁨(COMMON-P1-01)
  - 최종모델 2개(판정 기준·운영모델) 병존, 예측파일은 판정 기준 모델(A-P1-07)
  - "유의하게 우수" 과장(A-P1-06), LSTM-AE는 문헌값(COMMON-P2-04)
- **현재 점수**: **26** · 보수적 범위 21–29
- **핵심 감점 이유**: 확률 요건 미충족, 선정 순환논증, 과장 표현
- **수정 후 가능 점수**: 33
- **필요 작업**: 정상 데이터만 쓰는 선정 규칙, 블록 교차검증으로 간판 수치 교체, 보정확률 열, 최종모델 단일화

## 2. Plan C 문항별 채점

### 2.1 데이터 이해 및 진단 (15점)

- **충족 증거**: `data_audit.csv`(행·상태값·중복 TimeStamp·음수 dt·gap·burst·관측시간 vs 벽시계), gap-safe window 단위 테스트, 5개 연속 블록 검증전략, 독립 사건 1건 명시(`plan_c_submission/README.md:39-42`)
- **결손 증거**: 결측 1건으로 잘못 보고(C-P2-05), AI2 세션 교란을 진단하고도 모델 입력에 사용(C-P0-01), 정상 내부 운전변화 구간 미발견, 변수 단위 없음, 블록 CV를 "시간순"으로 표현(C-P2-07)
- **현재 점수**: **10** · 보수적 범위 8–12
- **수정 후 가능 점수**: 13 (A의 교란·운전변화 진단 흡수 시 14)

### 2.2 AI 예측모델 개발 및 성능평가 (40점)

- **충족 증거**: 베이스라인 B0 + 4개 모델(IF, Mahalanobis, PCA-MSPC, DPCA), 동일 fold·동일 q99.5 규칙, 3 seed, 정상 전체를 5블록 OOF로 테스트(0.556 h, Plan A의 4배), 오경보 중심 선정 규칙, 재실행 일치(F1 0.9492, AP 0.9936)
- **결손 증거**
  - **최종모델 IF의 성능·선정이 AI2에 의존**: AI2 제거 시 F1 0.893, 최악 경보 7건으로 자체 게이트 탈락(C-P0-01)
  - 선정 근거 2건 vs 5건이 통계적으로 구분되지 않음(p = 0.45), 강건성은 탈락 모델이 더 좋음(C-P1-02)
  - 예측파일로 계산한 F1 0.903 ≠ 보고 0.949(C-P1-01)
  - `fault_risk`가 확률이 아님(정상 51%가 0.5 초과, Brier 0.324 vs 0.027)(COMMON-P1-01)
  - "사전 고정" 입증 불가, 등록부와 설정 불일치(C-P1-03)
  - M1은 S+R, B1·M2는 A/S/R/O로 특징이 서로 달라 완전 동일 조건 비교가 아님
- **현재 점수**: **24** · 보수적 범위 18–28 (심사위원이 AI2 의존을 발견하면 하한)
- **수정 후 가능 점수**: 33 (A의 D1 흡수 + 재선정 + 보정확률 시 35)

### 2.3 영향요인 및 오류분석 (15점)

- **충족 증거**: 특징군 ablation, 채널 counterfactual repair, 22종 섭동, persistence 1/3/5, window 5/10/20, 상태별 집계(`error_conditions.csv`), 원인 단정 회피
- **결손 증거**: 섭동이 이상 window에만 적용되어 오경보 강건성 미측정(C-P1-04), 공정조건별 FN/FP 분해 없음(C-P1-05), "시간형태가 핵심" 결론이 AI2와 섞임, 설명 방법 간 불일치를 자체 규칙과 다르게 처리(C-P1-06), 상호작용 분석 없음
- **현재 점수**: **8** · 보수적 범위 6–10
- **수정 후 가능 점수**: 12 (A의 FP 구간 분석 흡수 시 13)

### 2.5 창의성·차별성 (10점)

### 7.3 유지할 평가 프로토콜

1. 정상: 5블록 OOF (총 0.556 h) — 블록별·합산 FP window, 경보 사건, Poisson 95% 상한(단측 0.95로 통일)
2. 이상: 동일 428 window를 fold별로 평가 → fold 평균 + **예측파일 pooled 지표** 병기, 유병률 명시(fold 약 12.5% / 파일 2.8%)
3. burst 단위: 17개 burst 중 탐지 수(사건 1건 내부)
4. **음성 대조군**: 정상 16,000–19,000행(블록 4 내부) window의 경보율을 "정상 운전변화 오경보율"로 별도 보고
5. 민감도: window 5/10/20, persistence 1/3/5, 분위수 0.99/0.995/0.999, 특징군 채널별 ablation, v1(AI2 포함) vs v2
6. 섭동: 22종을 **정상과 이상 window 모두**에 적용 → Recall 변화 + FP·경보 사건 변화

## 8. 우승을 위한 작업 순위

P0는 점수 상승과 무관하게 먼저 처리한다. 그다음은 점수 상승 / 시간 비율 순이다. 점수 상승은 **내용 기준 잠정 점수 대비 기대치**이고, P0 항목의 "평가 성립"은 점수로 환산하지 않는다.
