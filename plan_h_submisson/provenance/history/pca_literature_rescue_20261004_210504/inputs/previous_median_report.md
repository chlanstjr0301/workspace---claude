# PCA 실험 반증 검토 및 제한된 개선 탐색 보고서

작성일: 2026-10-04. 실행 폴더: `adversarial_pca_20261004_103236`. 로컬 CPU, 라이브러리와 코드 해시는 inventory.json과 manifests에 저장했다. 원본 CSV·ZIP·논문·이전 결과는 변경하지 않았다. 다른 에이전트의 새 실행 자료는 읽지 않았으며 Colab은 사용하지 않았다.

## 결론

**개선은 확인하지 못했다. 기존 P1·창20·2성분·Q·P0 보완·후처리 없음 구성을 유지하는 쪽이 현재 증거에 부합한다.** 기존 연구의 구현을 뒤집을 누출이나 Q/T² 계산 결함은 발견하지 못했다. 다만 한 날짜의 정상과 다른 날짜의 이상으로 이루어진 자료, 소수 버스트, 설정 선택의 불안정성은 남는다. 이 보고서는 기존 모델을 유지한다는 운영상 해석과 개발 규칙으로 고정한 신규 후보를 구분한다. 과거 평가를 보고 신규 후보를 재선택하거나 lock을 바꾸지 않았다.

기존 저장 모델을 별도 프로세스로 추론한 4,347행의 점수·판정이 원파일과 일치했다. 정상 학습 자료에서 PCA를 재학습해도 TP329/FN28/FP1/TN3989가 재현됐다. 같은 창20 IF도 저장 모델과 원점수 대조로 TP320/FN37/FP6/TN3984를 재현했다. 재학습 재현은 PCA 대표 구성에 대해 수행했고 IF는 저장 추론 재현으로 구분한다.

신규 선택은 **MEDIANIQR_Q: 창20, 센서별 중앙값/IQR 6특징, StandardScaler, PCA 2성분 Q, 동일 P0 fallback, 정상 보정 목표 FPR0.5%, 후처리 없음**이다. 내부 검증 이상99개 중83개 탐지·16개 미탐, 정상1,973개 중8개 오경보였다. 원15특징 PCA의 임계값만 0.1%로 바꾼 대조군(82TP/FN17/FP10)보다 내부에서 TP1 증가·FP2 감소했다. 하지만 이후 별도 개발 후반과 과거 평가 모두 악화했다. 이는 작은 개발 집합의 선택 이득이 다음 시간 구간으로 이어지지 않은 사례다.

과거 평가에서 신규 방식은 **실제 이상357개 중313개 탐지,44개 미탐; 정상3,990개 중3개 오경보; 정상1,000개 관측당0.752개 오경보**였다. 기존 방식은329개 탐지·28개 미탐·오경보1개(1,000관측당0.251개)다. Recall은92.1569%→87.6751%, F1은0.957787→0.930163, AP는0.987098→0.951304로 감소했다. FPR은0.0251%→0.0752%로 증가했다. 신규후보는 같은 창 IF보다 TP7 적고 FP3 적어 두 지표 모두 우월하지 않다.

## 2. 실제 확인된 결함·기각한 의심·한계

- **결과를 뒤집는 원구현 결함: 이번 범위에서 발견하지 못함.** 원논문이 PCA 자체의 신규성, 독립 고장 일반화, 실제 고장 전 예측을 주장했다고 해석하는 것은 부정확하다. 원고에 이미 한계와 동일창 IF 결과가 있다.
- **기각한 의심:** 센서 외 라벨/파일명/날짜 입력, 분할을 넘는 원시창 공유, 미래센서 참조, 최종자료로 scaler/PCA fit, full-rank Q, 0고유값 T² 나눗셈, 점수 방향 반전, best-seed 선택, point adjustment는 검사한 코드·재현 결과에서 발견하지 못했다. Q를 수동 중심화/투영식으로 다시 계산해 transform/inverse_transform 결과와 대조했다.
- **해석상 한계:** P1/P2의 native 평가만으로 버스트 처리 효과를 분리할 수 없다. 학습 창 수, 보정 분포, fallback 비율이 함께 바뀐다. 동일fit/commoncal/commoneval 대조를 추가했다. 원논문도 일부를 명시했으므로 새로운 누출 결함으로 부풀리지 않는다.
- **새로 확인한 선택 취약성:** 두 내부 시간블록에서 우수한 후보가 남겨둔 개발 후반에서도 나빠졌다. 목표 보정 FPR와 다음 구간 실제 FPR는 다르다. 원기준 P1의 내부 pooled FPR는 목표1%에서1.5712%로 미달했다.
- **현재 자료로 판단 불가:** 날짜/상태 교락, 실제 부하·압력·불량·정비와의 인과관계, 독립 설비·고장 일반화, 현장 오경보율, 고장 전 조기탐지. 버스트는 독립 고장 사건이 아니다. 10Hz만으로 앨리어싱을 확정하지 않으며 PCA의 면역성도 주장하지 않는다.

검토별 상태·근거는 critique_matrix.csv에 있다. 실행 중 pip 미설치와 분석 스크립트의 변수명 충돌은 이번 도구 실행 문제로 해결했으며 원연구 결함과 분리했다(logs/execution_issues.json). 후보 학습 실패/은폐는 없었다(logs/failures.json).

## 3. 사전 고정한 개선 설계

18개 기본구성×목표FPR0.1/0.5/1%=54개 운영구성, 선택 모델의 지속조건2개를 더해56개다. 정상fit·정상보정과 라벨을 쓰는 후보선택을 분리했다. PCA는 결정론적 full SVD이며 seed 반복을 하지 않았다. IF는42/43/44 고정 평균 점수 앙상블, 확인용45/46을 추가해 모두 공개했다. 신규 학습은 로컬 CPU2스레드에서2시간 이내로 끝났고 과도한 전조합·추가튜닝은 하지 않았다. 모드별 PCA는 부하정보와 독립 검증 자료가 부족하여 선택적 후보로 추가하지 않았다.

표준편차ddof0, 오른쪽 과거창, `>` 판정, `higher` 분위수, 동점 정상이다. Q95 배율 및 ECDF는 고장확률이 아니다. ECDF는 `(right_rank+0.5)/(n+1)`로 꼬리를 외삽하지 않아 최대값 이상의 점수가 포화된다. 라우트별 최소fit100행·정상보정50행을 고정했고 부족하면 동일길이 전체 정상보정으로 되돌린다. 운영시스템 전체 점수에서 임계값을 다시 정했다. 모든 설정은 protocol.json/hypotheses.md에 학습 전에 기록했다.

인과적 라우팅은 현재 버스트에서 사용 가능한1→3→5→10→20길이를 사용한다. 미래 burst_length는 선택 입력이 아니며 사후 오류분모에만 썼다. 시간상한2.5초 후보는 P1의20행 창 경과시간을 넘으면 동일P0로 되돌리는 별도정책이다. delta 후보는 P2 대비 평균변화량을 추가하므로 버스트 처리와 특징변경을 구분했다. 조건수는175.342, RMS²−mean²−std² 수치잔차 최대2.91e-11였다. 비선형 특징 중복은 확인됐지만 선형rank결함이나 수치붕괴가 자동으로 성립하는 것은 아니다.

내부검증은 시간순 두 블록이다. 정상학습12,012행/360버스트는 고정했다. 첫블록 정상보정1,019행/31버스트→정상평가992행/32버스트와 이상78행/2버스트, 둘째는 정상보정2,011행/63버스트→정상평가981행/29버스트와 이상21행/2버스트다. 남겨둔 개발후반은 정상1,005행/29버스트·이상90행/2버스트다. 이상보정 라벨은 이번 점수/임계값 적합에 사용하지 않았다. 동일 정상학습을 재사용하고 이전 블록의 정상평가 일부가 뒤 블록의 정상보정에 포함되는 순차 설계라 독립fold로 보지 않는다. 원연구가 이미 개발자료를 사용했으므로 후반도 새로운 독립 테스트가 아니다.

역할 경계에서 창을 초기화하므로 원논문 보정 구간을 재분할한 효과가 있다. 이 점은 기준선에도 동일하게 적용했다. 과거평가의 원대표판정과 새검토 기준선 판정은 동일했고 IF의 배율 앙상블 AP에만 미세한 차이가 생겼다. 데이터 분할별 모든 원시 행은 manifests에 남겼다.

선택 규칙은 내부 pooled FPR≤1% 중 Recall→F2→F1→AP이며 각블록 FPR와 최저Recall도 공개했다. 이1%는 프로젝트 가정이고 공식대회기준이 아니다. 두블록 모두1%를 요구하는 규칙으로 몰래 바꾸지 않았다. 선택된 median/IQR은 실제로 두블록 모두 제약을 만족했다. `frozen_selection.json`을 쓴 뒤 외부점검·과거평가를 실행했으며 결과를 보고 재선택하지 않았다. 이미 노출된 과거평가와 FN 사례가 시작부 가설에 영향을 준 이력은 명시한다.

## 5. 버스트·fallback·특징·결합 가설의 결과

H1: PCA/IF를 동일창20·센서·정상fit행·StandardScaler·normalcal·목표FPR·공통행에서 비교했다. 추가로 공통완전창 학습6,021행과 동일보정행만 쓰는 비교를 수행했다(tables/controlled_comparison.csv). 여기서는 P1/P2의 입력이 정확히 같아 각 알고리즘의 결과도 같다. 원래15특징 PCA와 IF의 전체운영 차이는 자체fallback과배율을 포함하므로 알고리즘만의 차이로 부르지 않는다. 입력과보정까지통제한 첫개발블록 target1%에서 PCA/IF 모두40개 이상을 탐지했지만 정상468개 중FP21/26으로 모두1%를 넘었다. 같은조건 PCA의 일관된 우월성은 확인되지 않았다.

H2: 시작부 집중 주장은 재현됐다. 원과거FN28 중26개가 첫19행, 개발원선택FN3·FP8도 첫19행이었다. 하지만 ROUTE_Q의 내부 target1% 결과는84TP/15FN/30FP로 기존85TP/14FN/31FP보다 낫다고 보기 어렵고 양쪽 모두제약미달이다. target0.1%에서도 라우팅81TP/13FP 대 임계값만 변경한P1 82TP/10FP여서 기각방향이다. 라우트별오류·보정표본수를 모두 공개했다. 모델 점수는 길이마다 정상보정으로정렬하고 임의의 원점수를 이어붙이지 않았다.

H3: P2와 경과시간상한도 내부검증에서Recall을 개선하지 못했다. 같은조건 target1% P1/P2는85TP/31FP 대63TP/29FP였다. 공통행만남기면 어려운시작부가 제외된다. 특히 둘째내부블록의 이상21행은 두짧은버스트라 공통B20행에는 이상이0개이며 해당구간 AP/ROC는 계산할수없다. 이를 완벽탐지나 모델우위로 해석하지 않는다. 표: tables/burst_comparison.csv, native_coverage.csv, route_metrics.csv, controlled_comparison.csv.

H4: median/IQR은 내부에서선택됐으나 다음구간에서악화했다. 다른축소특징·RobustScaler·성분3/5변경도 all_trials.csv에남겼다. 음의전류부호나 극단값을 삭제하지 않았다. 고차통계는추가하지않았다.

H5: 개발target1%에서 재보정QT는Q대비 추가TP0·잃은TP1, 추가FP17·제거FP19였다. 개별Q/T² 판정OR와QT는22행에서 달랐다. Q가놓친이상을T²가잡은행은0개이고 반대는16개였다. 결합이무조건검출을늘린다는 가설은지지되지않는다. ECDF도해상도/꼬리포화로일관된이득이없었다. tables/Q_T2_QT_complements.csv, threshold_calibration_audit.csv, calibration_tail_audit.csv가근거다.

## 7. 검증·수정·재현

저장된신규기준선/선택모델/IF를각각별도프로세스에서라벨없는CSV로추론해총13,041개판정을대조했다. 원행순서는원본manifest와연결했다. 각 모델의 두 파일 앞부분 총47행에서 미래 센서를 큰 값으로 바꾸고 burst_length·행번호·라벨을 바꿔도 과거 점수와 라우트가 변하지 않는 것을 검사했다. fit/calibration행집합,양성학습금지,원시창경계,수동PCA공식,작은고유값,Q유효rank,원본해시보존을검사했다. validation.json과saved_inference_validation.json이근거다. 추가진단/보고코드는선택후작성됐지만모델계산core와선택lock은그대로보존했다. 전체최종코드해시는MANIFEST_SHA256.json에서확인한다.

`bash RUN_REVIEW.sh`는동일프로젝트의새실행폴더에재현→개발→동결→검증→과거평가→분석→보고를다시실행한다. 설치된적합한프로젝트.venv를사용하며없으면명시적인오류로멈춘다. 환경복원은requirements.lock.txt를전용환경에설치한다. 기존실행결과를덮어쓰지않는다. 독립단일CSV추론은 `python src/infer_review.py --model models/final_MEDIANIQR_Q.joblib --csv INPUT.csv --target 0.005 --out NEW_OUTPUT.csv`다.

## 8. 한계와다음결정

개선실패는숨기지않는다. 내부1TP/2FP의이득은99개이상·소수버스트에서발견됐고별도후반에서즉시반전됐다. 현재자료로새규칙을계속탐색하면노출된평가에맞추기쉬우므로이번56개구성에서끝냈다. 유의성p값이나독립행신뢰구간을제시하지않았다. 버스트bootstrap도독립고장사건을보장하지않으므로새실증의대체물로추가하지않았다.

실제운영도입에는서로다른날짜에정상과이상이함께있는기록,설비/부하/유압/정비이력,실제고장시작시각,연속수집정상운전시간과현장오경보허용비용이필요하다. 미리봉인한새평가집합에서한번검증해야한다. next_data_requirements_ko.md에수집우선순위를남겼다. 기존평가6항목은패키지논문9쪽에서찾았으며rubric_evidence.csv로연결했다. 별도의공식대회채점표원문은이번자료에서독립적으로확인하지못했다.
