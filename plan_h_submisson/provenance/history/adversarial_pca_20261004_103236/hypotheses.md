# 사전 가설과 반증 조건

기존 과거 평가 결과와 오류는 이미 알려져 있다. 특히 첫19행 FN 집중이 H2의 착안이며 신규 선택에는 과거 평가를 사용하지 않는다. 아래 기준은 프로젝트 자체 설계다.

1. H1 알고리즘 효과: 동일15특징·창20·정상 fit행·scaler·보정·공통행에서 PCA Q와 IF를 비교한다. 전체 운영은 각자 fallback이므로 별도다. 동일조건에서 이득이 사라지면 알고리즘 우위 주장을 기각한다. 원모델의 임계값만 변경한 세 운영점도 포함한다.
2. H2 시작부 병목: 단일 P0와 버스트 인과적1→3→5→10→20 라우팅. normal cal route≥50, fit≥100을 사전 규정하고 sparse route는 동일 길이 전체 cal로 되돌린다. 개발에서 FN 감소 없이 FP만 늘면 기각한다. 미래 burst_length는 분석에만 사용한다.
3. H3 시간 혼합: P1/P2 동일조건과 P1 실제 경과시간≤2.5초 cap/P0를 비교한다. 전체와 공통행을 분리하고 native coverage 개선으로 해석하지 않는다. common-fit/common-cal 대조에서 일치 여부도 검증한다.
4. H4 특징 중복: RMS²=mean²+std²의 수치 잔차와 표준화 특징 조건수를 정상 학습에서 진단한다. full/compact/meanstd/medianIQR와 Standard/Robust를 한 요소씩 비교한다. delta는 버스트 내부에서만 계산하므로 P2를 대조군으로 사용한다. 성능 이득이 없으면 불필요한 특징 변경을 기각한다.
5. H5 점수 결합/정렬: Q/T²/max 재보정과 개별 OR를 구별한다. Q95 대 ECDF 비교, 표본 해상도와 꼬리 동점을 보고한다. Recall 이득이 FP 증가만으로 얻어지면 교환관계로 기록한다.

18기본구성×3목표FPR=54개, 최종 PCA 후처리2개=56개 이내. IF seed/fold는 반복이지 추가구성 아님. PCA seed 반복은 없음. 모드별 PCA는 추가하지 않는다. 모델 선택은 두 내부 시간블록 pooled FPR≤1%, Recall→F2→F1→AP. 각블록 준수/최저Recall 별도. 개발 후반을 외부점검으로 남기되 새로운 독립 자료로 부르지 않는다.
