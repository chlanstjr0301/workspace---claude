# 이 실험을 재현할 에이전트 명령문

동봉 README_ko.md, diagnosis_ko.md, protocol_v2.json을 읽고 고정 PCA 후속 v2 실험을 재현하라. Forest나 다른 PCA로 기준선을 바꾸지 마라. B0는 직전 baseline/original 모델이다. C0는 기존 R5_A0이며 C1은 B0 예측에 새 판정 함수만 적용한 대조다.

`bash RUN_EXPERIMENT.sh`를 실행해 새 디렉터리에 진단 재현, 정상C 분위수 검증, 최대6슬롯 선택, 설정 잠금, V 유지 확인, 통과 시 H 평가, 회귀검증, 보고서까지 저장하라. CPU2 threads로 진행하고 원본과 기존 결과를 수정하지 마라. 일반 실행 허락을 다시 묻지 마라.

S 합산에는 FN엄격감소/F2엄격상승/F1비하락을 요구하고, S1/S2/V에는 FN비증가/F2·F1비하락을 요구한다. 모든 해당 구간에서 추가FP≤floor(.001*Nnormal), 절대FPR≤1%를 유지한다. 이상 없는 블록은 FP만 평가한다. V의 FN0→0은 유지 통과이며 감소 재현은not_assessable다. 정책 수정으로 C0의 S2 실패를 취소하지 마라.

고정 R5 lag2 점수에 G0/G1/G2와 C higher분위수 .995/.999만 사용한다. B0 경보는 보존하고 현재 h가0이면 과거경보만으로 경보를 연장하지 마라. 과거값만 입력하고 파일/원분할/gap>.5초에서 보조 상태를 초기화한다. 시작행을 제외하지 마라. 중복 슬롯을 다른 실험으로 채우지 마라.

S에서 선정한1개를 잠근 뒤 V를 보고 실패하면 재선택하지 마라. V 유지 통과한1개만 H에서 평가한다. H를 보고 재튜닝하지 마라. 모든 자료가 재사용됐으므로 독립 검증/현장 개선 입증이라고 하지 마라. 실제고장시각이 없어 첫관측→첫경보와 실제고장탐지지연을 구분하라.

전체재실행의 수치와 판정을 원패키지와 대조하라. 차이가 있으면 해당 로그와 원인을 보고하고 데이터를 고쳐 수치를 맞추지 마라. 모델 성능 변화와 판정 정책 변화, C0 대비 잃은탐지/제거FP, B0 대비 추가탐지를 구분한 한국어 보고서를 제공하라.
