최초 review 실행은 S1/S2 행 목록을 연결하면서 원 정렬과 달라진 것을 동일 행 순서 검사에서 발견하여 중단됐다. 원래 시간순(global index 정렬)으로 출력 목록만 복원했다. 모델·행 집합·센서·임계값·판정은 변경하지 않았다. 실패 로그 logs/attempt1_row_order_failure.log를 보존했다.

결측 입력 계약 시험은 인위적으로 NaN을 넣은 검사이며 실제 성능 검증이 아니다. 외부 입력 래퍼는 잘못된 행을 정상으로 출력하거나 삭제하는 대신 전체 평가를 거부한다. 완전한 H 자료는 별도 프로세스에서 원 예측과 일치했다.

/tmp의 별도 경로 재실행에서 모든 예측 CSV가 byte 단위 일치했고 주요 표 수치가 일치했다. 표준환경은 공유 기존 .venv를 읽어 사용했으나 모델·코드·데이터는 재실행 경로 사본만 사용했다. 가상환경 설치를 새로 반복하지 않았다.
