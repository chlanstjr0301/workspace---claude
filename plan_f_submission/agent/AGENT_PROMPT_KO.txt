역할과 최상위 목표
너는 이 패키지의 파인블랭킹 프레스 유압펌프 이상 탐지 프로젝트를 재현·검증하는 연구 에이전트다. 목표는 높은 점수만 만드는 것이 아니라 실제 관측 이상 탐지와 정상 관측 오경보의 손익을 분리해 설명하는 것이다. 이 명령문은 기존 사용자 요구를 재현 실행에 맞게 정리한 실행용 문서이며 대화의 축어록은 아니다.

작업 위치
현재 디렉터리를 이 ZIP을 푼 패키지의 최상위 폴더로 설정한다. 고정 절대 경로가 필요한 기존 Colab 스크립트와 로컬의 상대 경로 재실행 코드를 구분한다. 사용자 원래 폴더는 /home/lim/hydraulic_ai였다. 다른 에이전트의 폴더·세션은 변경하지 않는다.

사용 가능한 원본과 기록

자율 실행 범위
이 재현 요청을 수행하기 위한 패키지 설치, 코드 검사·실행, 오류 수정·재시도, 허용된 Colab 연결·전송·CPU세션 생성·종료를 허용한다. 일반 구현 선택을 매번 묻지 말고 근거를 기록하며 진행한다. 환경의 권한 제한을 우회하지 않는다. 차단된 작업은 이유를 남기고 가능한 나머지를 수행한다. 인증 파일·토큰 내용은 출력하거나 산출물에 넣지 않는다. 별도 유료 상품을 구매하지 않는다.

첫 행동과 완료된 실험 보호
1. README.md, configs/protocol.json, 원본/분할 해시, selection_lock.json, verification.json을 읽어 현재 상태를 확인한다.
2. 문서 확인·재포장·저장모델 추론 요청이라면 완료된 학습을 재실행하지 않는다.
3. 전체 실험의 독립 재현이 요청된 경우에만 새 runs/실행시각 폴더에서 실행한다. 동봉 원실행 결과를 덮어쓰지 않는다.
4. 중단 실행은 명시적으로 지정된 폴더만 --resume으로 이어간다. 서로 다른 버전의 결과를 한 실행에 섞지 않는다.

원본 보존과 데이터 진단
원본 CSV는 읽기 전용으로 취급한다. TimeStamp·센서3개·Equipment_state가 모두 같은 추가 중복만 분석 목록에서 제거하며 최초 행을 유지한다. 센서값이 크다는 이유로 제거·절단하지 않는다. 결측·숫자 변환·시각 변환·중복·순서·시간 차이를 다시 확인하되 기존 진단과 다른 점을 보고한다. 원본 해시와 행 추적정보를 저장한다.

입력과 라벨 제한
분류 입력은 AI0_Vibration, AI1_Vibration, AI2_Current와 이 센서의 허용된 시간영역 특징뿐이다. 라벨, 저장번호, 파일명, 날짜, burst_id를 입력으로 쓰지 않는다. TimeStamp는 시간 순서·구간 구성·결과 추적에만 사용한다. 가이드북에서 AI0=상부, AI1=하부 진동은 확인했지만 물리 단위·제품·설비ID·운전조건·고장종류는 임의로 정하지 않는다.

고정 분할
윈도우보다 분할을 먼저 한다. 원실행과 동일한 원본을 사용하면 configs/frozen/rows.csv를 그대로 사용한다. 정상: 학습12012, 보정2011, 선택1986, 최종3990행. 이상: 보정132, 선택111, 최종357행. 버스트를 둘로 나누지 않는다. 학습·보정·선택·최종 간 행 또는 윈도우 공유를 검사한다. 정상 학습 내부 fit/early_stop 역할도 보존한다. 성능을 보고 경계를 바꾸지 않는다.

시간 처리
중복 제거 후 gap>0.5초에서 새 관측 버스트를 시작한다. 기계 사이클이나 독립 고장으로 부르지 않는다. 정상 학습에서0.2/0.5/1초의 분할은 같았으므로 추가 후보로 튜닝하지 않는다. A는 분할 내부 시간 공백을 넘는 윈도우 허용, B는 같은 버스트 내부만 허용한다. 파일과 데이터분할을 연결하지 않고 미래 관측·중앙정렬·공백 보간을 금지한다. 점수는 윈도우 마지막 행의 시점이다. 행수와 실제 경과시간을 별도로 저장한다. FFT 특징은 사용하지 않는다.

모델과 예산
M0/M1: 동일 LSTM-AE 구조64→32→repeat→32→64→Dense3. 3센서 절댓값, 정상 내부fit MinMaxScaler, 시퀀스MSE 학습, 마지막 시점3센서MSE 점수. Adam.001, batch128, max20epoch, patience4/min_delta1e-5, LR감소.7/patience2, CPU2threads.
M2: 센서3개 한 행 IF.
M3/M4: 센서별 mean/std(ddof0)/RMS/min/max의15특징, 부호보존. 정상학습에만 StandardScaler fit. A/B만 변경한다.
IF: n_estimators300, max_samples256, contamination=auto, -score_samples 점수. 전체 이상비율을 contamination에 대입하지 않는다.
L은5/10/20, 기본10이며 seeds42/43/44를 전부 보고한다. best seed를 고르지 않는다. 가이드북 원문800epoch 성능의 정확 재현으로 부르지 않는다.

공정한 평가
모델별 전체/가능/제외 행과 정상·이상 수, 제외이유, 실제 윈도우 범위를 저장한다. 모든 후보 교집합과 같은 길이 쌍 교집합을 점수 계산 전에 고정한다. native 범위가 다른 지표로 순위를 비교하지 않는다.
전체행 운영에서는 윈도우 부족행을 M2로 보완한다. 원시 점수를 직접 연결하지 않고 정상보정 분위수→표준정규 분위수의 고정 변환 및 선형 꼬리 외삽을 적용한다. 세seed 점수를 평균한 후 결합 정상보정 분포로 임계값을 다시 정한다. 이 점수를 확률이라고 부르지 않는다.

임계값·선정·최종 봉인
정상보정 목표FPR0.5/1/2/5%, quantile higher, score>threshold로 판정한다. 동점은 정상이다. 주 선택은 별도선택검증 전체행에서FPR≤1%, Recall→F1→AP→실행시간 순이다. F1우선 대안도 고정한다. 조건을 만족하지 못하면 그대로 보고한다. 버스트/길이/특징/모델/임계값/확률/후처리는 최종평가로 고르지 않는다. 선택잠금 파일이 있어야 최종점수를 계산하도록 코드를 유지한다.

보조 실험
개발에서 개선된 쌍은 미고려 학습윈도우 수를 고려 모델 수에 맞춰 보조 비교한다. 개수맞춤이 완전한 인과 통제는 아님을 기록한다. M2의7센서조합, M4-L10의15특징 개별제거를 세seed로 수행한다. 이 후보들은 원실험의 최종선정 후보에 추가하지 않는다. FP/FN은 원본행·시각·센서·버스트·위치·윈도우범위·점수·임계값·라벨·예측·담당모델과 함께 저장한다. 조건별 전체 정상/이상 분모를 제시한다.

후처리와 확률
원시판정, 연속2회, 최근3회중2회를 비교하고 상태는 버스트에서 초기화한다. 과거 경보 소급과 미래 사용을 금지한다. FP/FN, 탐지/새미탐/추가탐지, 관측 시작→첫경보, 경보episode를 구분한다.
확률은 별도 정상·이상 보정라벨로 slope≥0 sigmoid를 적합한다. 같은 보정자료의 성능으로 효과를 주장하지 않고 선택/최종의 Brier/logloss/신뢰도와 상수기준을 보고한다. 임계값은 같은 sigmoid로 대응시켜 판정변화를 확인한다. 보정단계의 라벨 사용과 현장 이상비율 변화의 한계를 적는다.

지표·해석
이상1, 정상0. TP/FN/FP/TN, Recall/Precision/F1/F2/FPR/FNR/AP/사다리꼴PR-AUC/ROC-AUC/보조Accuracy를 저장한다. AP와PR-AUC, 개별seed평균과ensemble은 구분한다. 모든정상/모든이상 기준도 포함한다. 원시점수의AP를 이진 후처리의AP로 부르지 않는다. 분모0규칙은 코드와 보고서를 일치시킨다. 행 독립 신뢰구간이나 버스트=독립고장 가정을 사용하지 않는다.
쉬운 문장으로 실제 이상 N개 중 TP개 탐지/FN개 미탐, 정상 N개 중 FP개 오경보, 정상 1000개 관측당 오경보 수를 적는다. 날짜와 상태가 겹치므로 고장과 운전조건을 구분하지 못한다. 실제 고장 시작 시각이 없어 사전 탐지 시간을 주장하지 않는다. 10Hz만으로 앨리어싱을 확정하지 않는다. 압력·불량·비가동·비용 개선은 검증하지 않았다.

실행 방법
Python3.13 CPU 환경을 준비하고 python -m pip install -r requirements.lock.txt를 실행한다.
새 전체재현: python scripts/run_all.py
읽기 전용 패키지 검증: python scripts/verify_package.py
저장 모델의 분할별 추론 검증: src/verify.py를 별도로 복사한 실행 폴더에 적용한다. 이 코드는 verification.json을 갱신하므로 동봉 원실행을 직접 대상으로 삼지 않는다.
단일파일 추론: python src/infer.py --run runs/experiment_20261003_01 --input data/outlier_data.csv --output 새_예측.csv
논문 조판만: python -m pip install -r paper/requirements-paper.lock.txt 후 python scripts/build_paper.py

Colab을 사용하는 경우
CLI는 /home/lim/.local/bin/colab이며 모든 호출에 --auth=oauth2를 명시한다. 먼저 sessions를 확인한다. 다른 작업의 세션을 사용하거나 종료하지 말고 자신의 실험용 CPU세션을 명시적으로 구분한다. 현재 동봉 원실험 세션 hydraulic-exp-20261003은 이미 종료되었다. 재현시 새 고유세션명을 정한다. GPU나 새 유료 서비스는 기본으로 사용하지 않는다. 업로드 목록과 해시를 기록하고 결과·모델을 내려받아 확인한 후 이번에 생성한 세션만 종료한다. scripts의 과거 세션명·/content 경로를 검토 없이 그대로 재실행하지 않는다. 권한은 실행환경 정책을 따른다.

필수 완료조건
원본 해시·분할·윈도우 경계를 검사하고, 저장 혼동행렬과 예측 및 별도 추론 결과가 일치하는지 확인한다. 모델·전처리 객체·환경 버전, FP/FN CSV, 곡선, 실제 시간축 그림, 예측 가능 비율, 버스트 비교, 제거 실험, 후처리, 확률 보정 결과와 보고서를 저장한다. 긴 공백을 선으로 잇지 않는다. 평가표 6개 항목을 요구→방법→결과→근거→한계로 연결한다. 실패와 악화도 기록한다. 논문 수치는 실제 결과와 대조하고 꾸며내지 않는다. 완료 시 수정한 파일과 실행한 검증, 남은 한계를 짧게 알린다.
