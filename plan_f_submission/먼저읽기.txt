프레스 유압펌프 이상 탐지 — 한국어 논문·코드·데이터 패키지 v1

1. 먼저 볼 파일
  paper/논문_한국어.pdf          17쪽: 본문 8쪽, 참고문헌·부록 9쪽
  paper/논문_한국어.docx         문장과 표를 수정할 수 있는 Word 원고
  paper/논문_한국어.html         브라우저로 읽는 같은 원고
  agent/AGENT_PROMPT_KO.txt     재현 작업을 맡길 에이전트 명령문
  agent/QUICK_START_KO.txt      복사해서 사용할 짧은 명령과 실행 예시

논문 제목:
관측 공백과 평가 범위를 분리한 유압펌프 이상 탐지:
버스트 처리·단일 행 보완·경보 후처리의 재현 평가

2. 실제 결과와 범위
선정 운영 방식은 M3-L20 Isolation Forest + 윈도우 부족 시 M2 보완,
세 seed 점수 결합, 최근 3회 중 2회 경보이다.
최종 이상 357개 중 303개 탐지, 54개 미탐. 정상 3990개 중 0개 오경보.
Recall 0.8487, Precision 1.0000, F1 0.9182, F2 0.8752, AP 0.9586.
이 결과는 동봉 고정 평가 자료에 한정된다. 현장 무오경보를 뜻하지 않는다.
정상과 이상이 서로 다른 날짜여서 고장과 운전조건의 효과를 분리할 수 없다.
실제 고장 시작 시각이 없어 고장 이전 조기 예측 시간은 검증하지 않았다.

  references/    가이드북에서 확인한 내용·쪽 번호·출처

4. 설치 없이 패키지 확인 (Python 표준 라이브러리만 사용)
압축을 풀고 이 폴더로 이동한 뒤:
  python scripts/verify_package.py
원본 2개와 원실행 877개 산출물, 전체 패키지 SHA-256을 검사한다.
데이터나 기존 결과를 쓰거나 학습을 다시 실행하지 않는다.

5. 독립적으로 실험 전체 재현 (Python 3.13 CPU 환경)
  python -m venv .venv
  .venv/bin/python -m pip install -r requirements.lock.txt
  .venv/bin/python scripts/run_all.py
Windows에서는 .venv/bin/python 대신 .venv\Scripts\python.exe를 사용한다.
마지막 한 명령이 전처리 검증→학습→평가→그림·보고서를 실행한다.
새 runs/실행시각 폴더에 저장하므로 동봉 완료 결과를 덮어쓰지 않는다.
논문을 읽거나 저장 모델을 활용하기 위해 재학습할 필요는 없다.
논문 본문은 동봉 원실행의 결과이다. 새 실행을 자동으로 같은 수치라고
간주하지 말고 환경·seed와 차이를 비교해야 한다.

저장 모델로 새 예측 CSV 생성:
  .venv/bin/python src/infer.py --run runs/experiment_20261003_01 --input data/outlier_data.csv --output 새_예측.csv
전체 원본 스트림의 추론과 분할별 최종 평가는 입력 범위가 다르다.
src/verify.py는 분할별 추론 일치 검사를 하지만 verification.json을
다시 기록한다. 원패키지를 보존하려면 별도로 복사한 실행 폴더에서 사용한다.

6. 논문 편집·재생성
  python -m pip install -r paper/requirements-paper.lock.txt
  python scripts/build_paper.py
편집 원본은 paper/manuscript.json이다. PDF·DOCX·HTML·TXT·Typst를 생성한다.
DOCX에서 직접 편집한 변경은 JSON에 자동 반영되지 않는다.
scripts/create_manuscript.py는 원실행 CSV에서 최초 원고와 표를 구성한다.
직접 편집한 원고를 유지하려면 이 초기 구성 스크립트를 재실행하지 않는다.
논문 재생성은 해당 논문 파일을 갱신하므로 수정용 폴더 복사본에서 권장한다.
패키지 해시 검사는 원배포본 기준이며 편집 후 불일치는 정상이다.

7. 연구 원고의 상태
ICML 수준의 엄밀성을 목표로 문제 정의·수식·비교 실험·실패 사례·재현성을
정리한 한국어 연구 원고이다. ICML 채택 수준이나 공식 제출 형식을
충족했다고 주장하지 않는다. 현재 근거는 단일 데이터셋의 제한된 날짜이다.
paper/SUBMISSION_READINESS_KO.txt에 후속 연구와 제출 준비 항목을 적었다.
저자·소속은 미기재이며 임의의 기관명·연구비·심사 결과를 만들지 않았다.

8. 원본·인증·권리
원본 CSV의 SHA-256이 기존 감사 기록과 일치한다.
인증 정보, 토큰, 가상환경, 다른 프로젝트·다른 에이전트 자료는 포함하지 않았다.
개인 워터마크가 있는 가이드북 전체 PDF는 제외하고 확인한 내용과 출처를
동봉했다. 해당 가이드북 없이도 동봉 설정으로 실험을 재실행할 수 있다.
데이터 출처와 구성요소별 권리는 RIGHTS_AND_SOURCES.txt를 참고한다.
