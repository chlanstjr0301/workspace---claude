## 해석과 한계

Balanced는 각 fold에서 n/(2*n_class)를 적용하므로 상대 이상 가중치는28.75지만 절대 가중치는 normal≈0.51739/abnormal=14.875다. 직접 지정 {0:1,1:w}와는 loss 전체 scale 및 L2 penalty 대비 효과도 다르므로 단순 ratio 동일 모델로 해석하지 않는다. 이 차이를 임의 rescaling으로 고치지 않고 요청한 class_weight 그대로 비교했다.

F1·Recall·Precision과 FP/FN 변화를 함께 판단한다. Recall<0.85는 표에 표시했다. 현재 CV에 의한 weight 선택 결과이며 같은 CV의 최고 성능은 선택 후 독립 평가 성능이 아니다. 반복 fold는 독립이 아니고 이상 burst가20개라 작은 평균 차이를 유의한 개선 또는 새 세션 일반화로 해석하지 않는다.

F1 공동 최고는 None 및 {0:1,1:3}이다. 사전 선택 규칙은 None을 선택한다. Balanced 대비 Precision +0.274550, Recall 동일, F1 +0.165473, FP -1.88, FN 동일, ROC-AUC -0.031130이다. 추천은 F1/Recall 기준이며 모든 지표의 우월함을 뜻하지 않는다.
