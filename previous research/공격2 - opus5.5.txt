================================================================================
[1] 절댓값(abs) — 방향은 맞으나 논증이 틀림
================================================================================

■ 공격1 논리의 결함
abs()의 정당화 조건은 "대칭성"이 아니라 "부호에 정보가 없을 것".
대칭성은 그 명제의 약한 따름정리일 뿐이고 역이 성립하지 않음.
또한 n=20,000에서 대칭성 검정을 돌리면 아무리 미세한 비대칭도 p<0.001로 나옴.
→ 통계적 유의성이 아니라 effect size(왜도 크기)로 따져야 함.

■ 대신 이렇게 공격할 것 (가이드북 [표 2]/[표 3] 수치가 그대로 증거)

  변수            정상 min/max            이상 min/max              판정
  -------------   ---------------------   ----------------------    ---------------
  AI0_Vibration   -0.3146 / 0.3517        -1.5027 / 1.8032          양(+)으로 비대칭
  AI1_Vibration   -0.3665 / 0.3998        -0.7513 / 0.5093          음(-)으로 비대칭

  정상은 양쪽 모두 거의 대칭.
  이상 데이터에서만 AI0는 +쪽, AI1은 -쪽으로 비대칭이 깨짐.
  → 상/하부 진동이 서로 반대 위상으로 치우친다는 뜻 (기어 편마모의 전형적 서명).
  → abs()가 지우는 비대칭이 바로 고장 신호 그 자체.

  핵심 문장: "대칭이라 괜찮다"가 아니라
             "대칭이 아닌데 지웠다, 그것도 하필 이상 데이터 쪽에서."

■ 두 번째 타격 — 전류에도 abs를 걸었음
코드 14의 use_col에 AI2_Current가 포함되어 있음.
  정상 전류 평균 1.446  →  이상 전류 평균 57.330
이 DC 오프셋 상승이 단일 최강 판별변수인데,
abs를 취하면 이것이 "진폭 증가"와 구분 불가능하게 뒤섞임.

■ 세 번째 타격 — 위상 파괴
abs는 전파정류(full-wave rectification)이므로 기본 주파수가 2배로 접힘.
LSTM에게 시간 구조를 학습시키겠다면서 입력단에서 위상을 파괴한 것.

■ 대안
 - 원신호 유지 + 윈도우 단위 통계 특징(RMS, kurtosis, crest factor, peak-to-peak)
 - FFT / envelope spectrum (베어링·기어 결함 진단의 정석)
 - 굳이 포락선을 쓴다면 abs가 아니라 Hilbert envelope

[2] K-fold — 질문을 바꿔야 함
================================================================================

답: "일반 K-fold는 불가, 변형은 가능, 그런데 써도 의미가 없다."
     → 세 번째 절이 포인트.

 - 일반 K-fold                     : 불가 (시계열 누수)
 - TimeSeriesSplit / rolling-origin: 가능.
                                     단 window(20) + horizon(100) = 120시점만큼
                                     purge + embargo를 둬야 윈도우 겹침 누수 방지
                                     (López de Prado, Purged K-Fold)
 - 그러나 이상 데이터는 2022-07-17 10:51부터 60초, 단일 연속 구간 1건.
   어떤 CV를 돌려도 고장 이벤트 표본 수는 n=1.
   → CV로 얻는 건 "정상 재구성 성능의 분산"뿐.
   → F1=0.7476의 불확실성은 원리적으로 줄일 수 없음.
      보고된 F1에 신뢰구간이 없는 게 아니라, 구할 수가 없음.

■ 진짜 공격은 threshold 설정 방식
코드 22: 이상 데이터 300개로 threshold를 맞추고, 남은 180개로 평가.
"정상 데이터만으로 학습하는 비지도 방식"이라고 내세워 놓고
결정 경계는 라벨로 지도학습한 것. 그것도 같은 60초 고장 구간 안에서.

증거: 검증 F1 0.847 → 테스트 F1 0.748 (과적합의 흔적)

■ 올바른 대안
threshold는 정상 재구성오차의 분위수(예: 99.5%ile)나 EVT-POT로만 결정하고,
이상 데이터는 최종 1회 홀드아웃 평가에만 사용.


================================================================================
[3] Loss Function — "MSE가 제일 나을 듯"은 틀림
================================================================================

■ 전제 오류
"절댓값이라 거리기반이니 MSE"는 성립하지 않음.
오히려 abs를 취했기 때문에 MSE가 부적절해짐:
정류된 신호는 half-normal에 가까운 우편향 분포가 되고,
MSE의 암묵 가정(가우시안·등분산)이 깨짐.
→ Huber / log-cosh / MAE가 이론적으로 더 적합.

■ 다만 Loss는 곁가지. 진짜 문제는 평가 스코어.

코드 28:
    flattened[i] = X[i, X.shape[1]-1, :]     # 윈도우 20시점 중 마지막 1개만

20시점 전체를 복원하도록 학습시켜 놓고,
이상 점수는 마지막 1시점의 MSE로만 계산.
→ 학습 목적함수와 평가 스코어가 불일치
→ 복원한 정보의 95%를 폐기
"어떤 Loss가 나은가"보다 훨씬 구체적이고 반박 불가능한 결함.

■ 치명타 — 스케일링 누수 (이 절 전체의 핵심)

코드 20: MinMaxScaler를 정상 데이터에만 fit.
그런데 이상 데이터 진동 진폭은 정상의 약 5배 (0.35 → 1.80).
스케일링하면 이상 샘플은 [0,1]을 한참 벗어난 값으로 입력됨.

→ 재구성 오차가 큰 이유가
   "AE가 학습한 시간 패턴에서 벗어나서"가 아니라
   "그냥 값이 범위 밖이라서".

→ 이 모델은 LSTM-Autoencoder의 탈을 쓴 진폭 임계값 검사기.

■ 결론: 본 논문 최대 결함 = 베이스라인 부재
윈도우 RMS 단일 임계값만으로 동등하거나 더 나은 성능이 나올 가능성이 매우 높음.
이것을 실증하면 선행연구가 통째로 무력화됨. 대회에서 가장 비싼 한 방.


================================================================================
[4] Blackbox vs Whitebox — 맞지만 전제가 틀림
================================================================================

■ 전제 오류
"precision을 좀 포기하더라도"라는 트레이드오프가 이 데이터에선 성립하지 않음.
[3]절 논리대로면 whitebox가 더 정확할 가능성이 높음.
F1 = 0.7476은 변명의 여지 없이 낮은 수치.

■ 구체적 대안
 - PCA 기반 Hotelling T² + SPE(Q통계량)
   : 공정관제의 정석. contribution plot으로 "어느 센서가 범인인지"까지 출력.
     현장에서 "경보 떴음"과 "하부 진동 채널이 범인임"은 가치가 완전히 다름.
 - 윈도우 통계 특징(RMS, crest factor, kurtosis, 채널 간 위상차)
   + Isolation Forest / One-Class SVM / Mahalanobis distance
 - either/or로 갈 필요 자체가 없음:
   LSTM-AE를 유지하면서 채널별·시점별 재구성 오차를 분해하면
   해석성이 그냥 따라옴. "희생"이 아니라 "추가"로 프레이밍하는 게 심사에서 유리.

[5] 공격1이 놓친, 더 센 공격 4개
================================================================================

■ ① "예지보전"이 아니라 그냥 "이상탐지" (최우선)
이상 데이터는 Equipment_state == 1, 즉 이미 고장 난 상태의 60초.
고장 전조 구간이 아님. RUL도, 열화 추세도, 선행 경보 리드타임 검증도 없음.
제목·목적·시사점 전부가 "사전 예측"을 주장하는데 실제로 한 것은 사후 탐지.

추가로, 코드 21의 +100(10초)을 근거로 "100시점 이후를 탐지"라 서술하지만
fit(X_train, X_train)이므로 모델은 예측을 전혀 수행하지 않음.
그 오프셋은 라벨 인덱싱일 뿐. → 문서 서술과 코드가 불일치.

■ ② 교란변수 — 정상 7/12, 이상 7/17, 다른 날 수집
부하·소재·금형·유온 등이 통제되지 않음.
모델이 배운 것이 "고장 vs 정상"인지 "7월 12일 vs 7월 17일"인지
구분할 방법이 없음. → 인과 주장 자체가 무너짐.

■ ③ Train/Test 사이의 체제 변화(regime shift)
코드 12·15 그래프에서 15,000 지점 근방에 AI0 진폭과 AI2 전류의 뚜렷한 하락.
그런데 분할이 하필 X_normal[:15000] / X_normal[15000:].
→ 학습 정상 분포 ≠ 테스트 정상 분포.
→ 정상 78건 오분류(FPR 1.95%)가 고장 신호가 아니라 분포 이동 탓일 공산이 큼.

■ ④ 10Hz 샘플링으로 모터 진동을 논하는 것 자체
초당 10회 샘플링 → Nyquist 5Hz.
유압펌프 기어 맞물림 주파수는 수백~수천 Hz 대역.
→ 수집된 "진동"은 파형이 아니라 완전히 aliasing된 신호.
→ LSTM이 학습했다는 "시간적 패턴"에 물리적 의미가 없음.

역설: abs 후 진폭만 쓰는 게 이 센서로 할 수 있는 거의 유일한 처리인데,
      그렇다면 LSTM을 쓸 이유 자체가 사라짐.
      → [1]절 abs 공격과 가장 깔끔하게 연결되는 고리.

  normal : 20,000행인데 span 4,616초. 10Hz 연속이면 2,000초여야 함.
           0.5초 초과 공백 598개 → burst 599개.

  outlier:    600행, span 166초 (연속이면 60초). burst 21개, max 50.

   (b) naive windowing의 20샘플 윈도우 상당수가 gap을 가로지른다(= 가짜 2초 윈도우).

       → [5]④의 10Hz aliasing 공격과 중첩되어 결정타가 된다.

[9-1] 전략 3 — abs() 불변성 (학습 윈도우 7,145개 기준)
--------------------------------------------------------------------------------
  특징별 |raw 값 - abs적용 값| 최대 차이:
    RMS   0.000e+00  불변        MEAN  2.208e+02  변형됨
    MAV   0.000e+00  불변        AMEAN 1.488e+02  변형됨
    PEAK  0.000e+00  불변        STD   1.124e+02  변형됨
    CREST 0.000e+00  불변        P2P   2.995e+02  변형됨
                                 KURT  4.951e+00  변형됨

  핵심 논증 (반박 불가):
    RMS = sqrt(mean(x^2)) 는 |x|^2 == x^2 이므로 abs 에 대해 '정확히' 불변.
    즉 가이드북이 코드 14에서 파괴한 정보는 RMS가 애초에 쓰지 않는 정보다.
    LSTM-AE가 RMS 베이스라인을 이길 수 있는 유일한 근거는 부호/위상 구조인데,
    가이드북은 그 구조를 입력단에서 스스로 제거한 뒤 LSTM을 돌렸다.
    → "왜 LSTM인가"에 대한 답이 원리적으로 사라진다.

  실측 왜도 (abs가 지우는 바로 그 신호):
    AI0_Vibration  정상 skew +0.0225  →  이상 skew +0.3854
    AI1_Vibration  정상 skew +0.3129  →  이상 skew -0.5857   (부호 반전)
    AI2_Current    정상 skew -0.0019  →  이상 skew +0.1513
    AI0는 +, AI1은 - 로 서로 반대 방향 비대칭 → [1]절 주장 실측 확인.

--------------------------------------------------------------------------------
[9-3] 결론 — 공격 문장으로 바로 쓸 수 있는 형태
--------------------------------------------------------------------------------
 1. 가이드북 LSTM-AE(F1 0.7476)는 학습 없는 단일 임계값 규칙에 진다.
    동일 조건·라벨 미사용에서 F1 0.8197, 오경보 0건.
 2. 물리적으로 타당한 windowing으로 바꾸면 격차가 F1 0.9694 대 0.7476 으로 벌어진다.
 3. LSTM-AE의 재구성 오차는 시간 패턴이 아니라 진폭/오프셋을 재고 있다.
    근거: RMS는 abs에 불변인데도 LSTM-AE를 이긴다 = 딥러닝이 쓴 정보도 그 수준이다.
 4. 가이드북의 "10초 뒤 예지" 서술은 데이터 구조상 성립 불가 (burst 최대 5.0초).
