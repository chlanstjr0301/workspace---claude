## 평가 조건 (전 검증 공통)

```
windowing : gap-aware (dt > 0.5 s 로 끊고 run 내부에서만 생성), SEQ=20, offset=0
분할      : train normal[:12000] / valid normal[12000:15000] / test normal[15000:] + outlier 전체
window 수 : 정상 9,978 (train 6,021 / valid 1,468 / test 2,489) / 이상 276
임계값    : 정상 검증구간 q99.9  — 이상 라벨 미사용
특징 13개 : 채널별 {acf1, acf2, std, ptp} × 3 + corr(AI0,AI1)
```

> **주의**: Plan A 문서가 "정상 2,489"라 쓴 것은 전체가 아니라 **테스트 몫**이다. 전체는 9,978이다.

## `_agent_raw/` 에 대하여

적대적 검증에 투입한 에이전트 4기가 각자 작성한 원본 스크립트다. **세션 임시 디렉터리에 있던 것을 출처 보존 목적으로 옮겨왔다.**

- 경로가 원래 임시 디렉터리 기준이라 **그대로는 실행되지 않는다.** 재현은 `verify_attack4.py`를 쓸 것.
- 문서에서 ◇(에이전트 보고, 미재현)로 표시한 항목 — seed 20개 스윕, 블록 부트스트랩 CI, conformal 위반 배수, AI2 캐리어 파워비, Ljung-Box, 상·하부 진폭비 — 의 원 계산이 여기 들어 있다.
- 매핑: `a1_robust`(seed·분위수·ne) / `a2_ai2`(AI2 교란) / `a3_regime`(변화점) / `a4_boot`(블록 부트스트랩) / `a5_algos`(알고리즘 교차·conformal) / `a6_pca`·`a7_verify`(PCA·Mahalanobis) / `a8_select`(선택편향·FAR/h) / `a9_final`(상관 반전) / `phys1`~`phys5`(물리·스펙트럼·센서) / `probe1`~`probe6`(코드 감사)
