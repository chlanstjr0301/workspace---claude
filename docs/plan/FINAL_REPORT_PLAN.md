## 2. 서사 재정의 — 핵심 결정 6개

### N1. 기여의 중심을 "2단 확인 구조"로 옮긴다

- **근거** (v2a, v2c, v2d): 1단에 어떤 후보를 넣어도 같은 2단 확인 + 3연속 안에서는 빨강 성능이 비슷하거나 낫다.
  - 1단을 BL-0로 두면 동결 분할 FP 0, 5-fold F1 0.924
  - 제출본 M3는 동결 분할 FP 3, 5-fold F1 0.919
  - 섭동 36조건에서도 BL-0 시스템이 M3 시스템과 같거나 낮다
- **본문 메시지**: "빨강 성능은 1단 모델 선택보다 2단 진동 확인과 연속 확인 구조가 만든다. 1단 M3를 고른 실익은 노랑 단계의 섭동 안정성(최악 27.5% 대 BL-0 46.7%)과 등급 점수다. BL-0는 보정점수의 98.6%가 동점이라 위험 순위·확률·확인 후보를 낼 수 없다."
- 불리한 결과를 숨기지 않으면서, **구조 설계 자체의 기여**로 읽히게 쓴다(5장 창의성과 연결).

### N2. 교란 서사를 "수집 경로 차이 → 판정 기전 → 3중 방어"로 바꾼다

1. **수집 경로가 다르다** (v1a): 고장 전류만 1.192 간격 격자 위에 있다(고유값 340/600). 진동 저장 자릿수도 6 대 11이다.
2. **판정은 직류가 아니라 전류 파형 형태에서 온다**
   - v1c: 고장 전류의 직류를 옮겨도 판정이 그대로다.
   - v1e: 단일 특징 1위는 전류 0.1초 자기상관(AUROC 0.986)이다.
   - 기존 1.1의 "직류 성분 차이" 설명을 교체한다.
3. **방어 근거 3개**
   - (a) 빨강은 전류를 보지 않는 2단 확인을 요구한다.
   - (b) 진동 진폭 특징만으로 AUROC 0.995, 정상 경보율 0.27%다(v1d).
   - (c) **가짜 고장 대조**(w2b): 정상 데이터끼리 시간구간만 나눈 가짜 과제에서 같은 진동 진폭 모델의 AUROC는 평균 0.538, 최대 0.576이다. 실제 고장은 0.995다. 수집 시점 차이만으로는 이 분리 크기를 설명하지 못한다.
- **한계 문구**: 센서 재부착·감도 변경은 배제할 수 없다.

### N3. 과제를 "실시간 이상 판정"으로 재정의한다 (측정 근거 포함)

- **w3a**: 고장 전 정상 구간이 0초다.
  - 상태 전이 0건
  - 첫 평가 window부터 경보
  - 고장 window의 1단 p값 고유값이 1개(포화)
  - 경과시간과 점수의 추세는 오히려 음수(ρ −0.14, −0.25)
- **본문 문구**: "이 데이터에는 사전 경고 구간이 구조적으로 없다. 본 시스템이 제공하는 것은 실시간 이상 판정이며, 확인 지연은 중위 0.2초(최대 0.7초)다." 출처는 w4b와 표 B-1.
- 발표 Q&A "왜 조기탐지가 아닌가"의 답으로도 쓴다.

### N4. 성능은 점추정과 구간을 함께 쓴다

- 표 2-8에 버스트 부트스트랩 95% 구간을 붙인다(v3a): 빨강 F1 0.931 [0.892, 0.955], FPR 0.10% [0, 0.28%], Recall 0.876 [0.812, 0.920].
- "80분의 1"은 반드시 "평가 블록 기준"으로 한정한다. 정상 전체 기준(3.14% → 0.24%, 약 13분의 1)을 함께 적는다.

### N5. 확률 서술을 정직하게 낮춘다

- 고장 window의 1단 p값은 바닥에 포화되어 고유값이 1개다(w3a). 그래서 `risk_score`는 심각도 눈금이 없다.
- `anomaly_prob_cal`은 "이 고장 기록 안에서의 보정값"으로 서술한다.
  - 계산 방식을 정확히 쓴다: 정상 행에는 고장 전체로 적합한 보정기를 쓰고, 음성은 학습 표본 안의 점수다.
  - 5장 성과 목록에서 뺀다.
- 현장 확률 판단은 사후확률표로 한다. 보수 열은 버스트 부트스트랩 값(v3b)으로 바꾼다.

### N6. 운영 기준을 교대 단위로 확정한다

- 빨강 단건은 8시간 교대당 61건(95% 상한 192)이다(v5a, 수집 비율 0.40).
  - **단건 = 확인 대상**
  - **정지 검토 = S2(인접 버스트 연속 빨강)**: 정상 5블록에서 0회 발동, 고장 기록에서는 첫 평가 window 후 7.1초에 발동(v5b)
- 빨강 권고 문구를 2단 진동 근거로 만든다(v5c·v5d, 고장 빨강의 98%가 진동 진폭). 적용 여부는 **사용자 결정 D1**.
