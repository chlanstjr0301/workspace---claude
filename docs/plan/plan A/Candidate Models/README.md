## 1. 모델 선택을 좌우하는 제약

`../Model Performance Indicators/README.md`에서 확정된 것 중 모델 선택에 직접 걸리는 것만.

| 제약 | 모델 선택에 미치는 영향 |
|---|---|
| 양성 이벤트 **1건** (버스트 13개) | **지도학습 사실상 불가.** 1개 샘플을 학습하는 것과 같다 → **단일클래스(정상만 학습)가 기본** |
| 버스트 수집 (≤50샘플 = 5 s) | 입력 길이가 20샘플로 제한. **긴 시퀀스 모델(Transformer, 장기 LSTM) 부적합** |
| gap-aware window 정상 2,489 / 이상 276 | 학습 표본 6,021개. **파라미터 수만 개 짜리 딥모델은 과적합** |
| 문항 2 "이상 **확률**을 예측" | 점수가 아니라 **확률 출력이 요건**. 확률화 레이어 필수 (§4) |
| 문항 3 영향변수·상호작용 | **설명 가능해야 한다.** 기여도 분해가 되는 모델 우선 |
| 10 Hz 샘플링 (Nyquist 5 Hz) | 펌프 축 회전수(통상 ~30 Hz) **보다 낮다** → **FFT 베어링 결함주파수 분석 불가**. 시간영역 통계특징이 정답. 이 판단 자체를 보고서에 쓰면 제조지식 득점 |

> **"왜 Transformer/TranAD 같은 SOTA를 안 쓰는가"** 에 대한 답을 미리 준비해둘 것: 입력이 20샘플 × 3채널이고 학습 표본이 6천 개다. 모델 용량이 문제가 아니라 **표본이 문제**다. 이 판단을 근거와 함께 쓰는 것이 무작정 큰 모델을 쓰는 것보다 점수가 높다.

**제조지식 연결**: 상부·하부 진동센서가 **역위상**으로 움직인다는 것은 펌프 본체가 한 덩어리로 흔들리는 게 아니라 **축을 중심으로 흔들리는(rocking) 운동**이 생겼다는 뜻이다. 정렬불량·체결 이완·베어링 유격의 전형적 신호다. 또한 정상의 백색잡음이 **저주파 상관 운동**으로 바뀐 것은 캐비테이션이나 유압 맥동의 전형이다.

→ **문항 3의 "변수 간 상호작용"에 그대로 쓸 수 있는 재료다.** 단순 상관계수 나열이 아니라 물리 해석이 붙는다.

**결과**: 학습구간(:15000)으로 적합한 단일클래스 모델은 테스트 정상구간(15000:)을 **진짜로 낯설게 본다**. 실측으로 Mahalanobis(13특징)가 FPR **20.5 %**, IF(ACF 포함)가 FPR 4~8 %를 냈다. 모델 잘못이 아니라 **분할이 체제 경계를 가로지른 탓**이다.

> 가이드북 LSTM-AE의 FP 78개(1.95 %)도 같은 현상일 가능성이 높다. 이상 데이터로 임계값을 느슨하게 맞춰 가려졌을 뿐이다.

**→ 모델 선택에 주는 지침**: ACF·상관 특징은 **체제에 민감**하다. 쓰려면 **체제 상대 정규화**(최근 정상 구간 기준 z-score) 또는 **체제별 기준선**이 반드시 함께 가야 한다. 그냥 넣으면 성능이 떨어진다 — 실측으로 확인했다(§3).

>
> **대회 전략**: 이 변수를 쓰면 F1 0.922가 공짜로 나온다. 쓰지 않고, **"왜 버렸는지"를 수치와 함께 쓰는 것**이 문항 3(오류분석)·문항 5(차별성)에서 훨씬 비싸게 팔린다. 다른 팀은 십중팔구 이걸 모르고 쓰거나, 모르고 안 쓴다.
>
> 단, 단정하지 말 것. 이벤트가 1건이라 "세션 지문"과 "실제 고장 신호"를 완전히 구분할 수 없다. 보고서에는 **"배제 근거와 함께 민감도 분석(포함/제외 양쪽 성능)을 제시"** 한다.

## 4. 확률화 레이어 — Conformal Anomaly Detection (최우선 권장)

**문항 2가 "제조 이상 *확률*을 예측하는 모델"을 요구하는데, 위 후보들은 전부 점수(score)만 낸다.** 확률화가 별도 레이어로 필요하다.

### 왜 Platt/Isotonic이 아니라 Conformal인가

| | Platt / Isotonic | **Conformal** |
|---|---|---|
| 필요한 데이터 | **이상 라벨 필요** | **정상만** |
| 우리 상황 | 이벤트 1건으로 적합 → 사실상 그 이벤트에 과적합 = 누수 | 누수 없음. §5 T2 원칙과 일관 |
| FPR 보장 | 없음 | **교환가능성 하에 FPR ≤ α 이론 보장** |

**작동 방식** (단순함이 장점):

```
1. 정상 검증구간 window 들의 이상점수 {s_1 ... s_m} 를 보관 (calibration set)
2. 새 window 점수 s 에 대해
       p = (1 + #{i : s_i >= s}) / (m + 1)        <- conformal p-value
3. 이상 확률 = 1 - p
4. p <= alpha 로 경보 -> 장기 오경보율이 alpha 이하임이 보장된다
```

**이 한 기법이 가져오는 것**

| 얻는 것 | 해당 배점 |
|---|---|
| 교정된 **확률** 출력 | 문항 2 "확률" 요건 (40점) |
| **확률보정** | 문항 5 명시 키워드 |
| **불확실성 추정** (p-value가 곧 불확실성) | 문항 5 명시 키워드 |
| FAR 제약을 *설계로* 보장 (α 지정 = FAR 지정) | 문항 4 + 성과지표 §4.1 P2 |
| 앙상블 시 p-value 결합(Fisher/Stouffer)으로 보장 유지 | 문항 5 **앙상블** 키워드 |

→ **문항 5의 명시 키워드 5개 중 3개를 단일 기법으로 덮는다.** 투자 대비 회수가 가장 크다. 구현도 위 4줄이 전부다.

> **주의**: 교환가능성 가정은 §2.2의 체제 변화 때문에 깨진다. 그래서 **체제별 calibration set** 또는 **최근 구간 기준 적응형 calibration**이 필요하다. 이 한계를 보고서에 명시하는 것 자체가 문항 3 재료다.

## 5. 후보별 상세

### BL-1 · PCA 기반 MSPC (Hotelling T² + SPE/Q) — 가장 과소평가된 후보

제조 공정관리의 **표준 방법론**(Multivariate Statistical Process Control)이다. 딥러닝보다 먼저 제안돼야 한다.

| 항목 | 내용 |
|---|---|
| 출력 | T² (주성분 공간 내 이탈) + SPE/Q (주성분 공간 밖 이탈) **2종** |
| 확률 | 두 통계량 모두 **관리한계가 이론적으로 유도**된다 (T²는 F분포, Q는 χ² 근사) → 확률 즉시 |
| 설명력 | **기여도 플롯(contribution plot)** — "어느 변수가 이 경보에 얼마나 기여했는가"를 바로 분해. 문항 3 "주요 영향변수"의 **현장 표준 도구** |
| 상호작용 | **공분산 구조를 명시적으로 모델링** → §2.1의 corr(AI0,AI1) 반전을 T²가 직접 포착 |
| 비용 | sklearn `PCA` 몇 줄. 학습 1초 미만 |

**추천 이유**: 문항 2(확률)·3(영향변수·상호작용)·4(현장 표준이라 설득력)·5(제조지식 결합)를 **동시에** 친다. 평가자 중 "산"과 "연"에게 특히 잘 먹힌다 — 현장에서 실제로 쓰는 방법이기 때문이다.

### M-1 · Isolation Forest (진폭 6특징) — 현재 최고 성능

- 실측 **F1 0.864 / Precision 1.000 / FPR 0.0000** (§3)
- 특징: `AI0_std, AI0_ptp, AI1_std, AI1_ptp, AI2_std, AI2_ptp`
- 설명력: 특징이 6개뿐이라 permutation importance·SHAP 모두 가볍게 적용 가능
- 보강 과제: Recall 0.761 → 1.0. 체제 상대 정규화를 더한 ACF 특징을 **조건부로** 투입해 볼 것

### M-2 · LSTM-AE (가이드북 재현)

- **반드시 재현해야 한다.** 가이드북 수치(F1 0.748)는 naive windowing 기준이라 BL-0(0.818)과 직접 비교 불가다. 동일 조건에서 다시 재지 않으면 "베이스라인 대비 개선" 주장이 성립하지 않는다.
- 하이퍼파라미터는 가이드북 그대로(LSTM 64-32-32-64, seq 20, MSE) 두되 **임계값만 T2(정상 q99.9)** 로 바꿔 누수를 제거한 버전도 함께 측정 → 임계값 선택이 성능에 미치는 영향을 분리해서 보여준다. 문항 3 재료.

### M-3 · 1D-CNN AE + MC-Dropout

- 입력이 20스텝뿐이라 **LSTM의 장기기억이 쓸모없다.** 1D-CNN(kernel 3~5) 오토인코더가 파라미터는 1/5, 학습은 몇 배 빠르다. "왜 LSTM 대신 CNN인가"를 쓰면 문항 2 선정근거 점수.
- **MC-Dropout**: 추론 시 dropout을 켜고 T회 통과시켜 재구성오차의 **분산**을 얻는다 → 불확실성 추정 키워드. §9 "확신 표시"와 연결.

### M-4 · Conformal 앙상블

- 구성: BL-1(T², SPE) + M-1(IF) + M-3(AE) 각각의 conformal p-value를 **Fisher 결합**
- 장점: 서로 다른 실패 모드를 덮는다. 진폭 기반(IF)과 공분산 기반(T²)은 놓치는 지점이 다르다
- 문항 5 "앙상블" 키워드를 **확률 보장을 유지한 채** 확보

### 대조군 · LightGBM (지도학습) — 실패를 보여주기 위해 넣는다

양성 이벤트 1건을 지도학습하면 날짜 교란을 학습한다. §6.3 E1~E3 통제실험에 걸리게 만들어 **"왜 지도학습을 최종모델로 쓰지 않았는가"** 를 수치로 답한다. 발표평가 방어용으로도 유용하다.

### 제외 후보와 이유

| 제외 | 이유 |
|---|---|
| Transformer / TranAD / Anomaly Transformer | 입력 20스텝, 학습 표본 6천. 표본이 모자라지 모델 용량이 모자라지 않다 |
| One-Class SVM (RBF) | O(n²) 학습, 확률 보정 어려움, 기여도 분해 불가 → 설명력 요구와 충돌 |
| FFT / 포락선 분석 / 베어링 결함주파수 | **Nyquist 5 Hz < 펌프 축 ~30 Hz.** 물리적으로 불가 — *다만 "왜 불가한지" 설명은 제조지식 득점이므로 보고서에는 넣는다* |
| SMOTE 등 오버샘플링 | 양성이 단일 이벤트에서 나온 중첩 window라 합성해도 정보가 늘지 않는다. **안 쓰는 이유를 쓰는 것**이 문항 5 득점 |

## 7. 실행 순서

1. **BL-1 (PCA MSPC) 구현** — 가장 싸고 가장 많은 문항을 친다. 반나절
2. **Conformal 래퍼 구현** — BL-0·BL-1·M-1에 공통 적용. 코드 4줄. 반나절
3. **M-1 보강** — 체제 상대 정규화를 더한 ACF 특징을 조건부 투입, Recall 0.761 → 목표 1.0
4. **M-2 LSTM-AE 재현** — 동일 조건 재측정 (누락 시 "개선" 주장 불성립)
5. **M-3 1D-CNN AE + MC-Dropout**
6. **M-4 Conformal 앙상블** → 최종모델 후보
7. **대조군 LightGBM + E1~E3 통제실험** → 문항 3 본문
8. 전 후보에 §8 FN/FP 조건별 분해표 적용

> **합격선 재확인** (`../Model Performance Indicators/README.md` §7.3): `F1 > 0.818` **그리고** `FAR/h ≤ 1` **그리고** `Event Recall = 1.0`.
> 현재 이 셋을 모두 통과한 후보는 **아직 없다** — M-1이 F1·FPR은 통과했으나 Event Recall 미측정이다.
