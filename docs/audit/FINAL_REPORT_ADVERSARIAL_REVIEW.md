## 3. 새로 드러난 사실 — 두 파일의 수집 경로가 다르다

검토자 ③이 발견했고 종합자가 다시 확인했다.

| 항목 | 정상 파일 | 고장 파일 |
|---|---|---|
| 전류 고유값 수 | 19,934 / 20,000 | **340 / 600** |
| 전류값의 1.1920929 격자 잔차 최대 | 0.4999 (격자 없음) | **0.00005 (격자 위)** |
| 저장 자릿수 | 진동 소수 6자리 | 진동 소수 8~10자리 |

- **해석**: 고장 파일은 다른 수집·내보내기 경로(양자화 해상도가 다른 ADC 또는 단정밀도 변환)를 거쳤다. 날짜 교란은 막연한 "운전조건 차이"가 아니라, 계측 경로 차이로 데이터에 직접 드러난다.
- **검토자 ③의 추가 진단** (동결 모델 사용, 재현 필요):
  - 분리력이 가장 큰 단일 특징은 전류 lag-1 자기상관이다(평가 블록 0.807 대 고장 −0.034, AUROC 0.986).
  - 고장 전류의 직류 성분을 정상 평균으로 옮겨도 1단 AUROC 1.0000, 빨강 Recall 0.876으로 그대로다. 즉 **판정에는 직류가 아니라 전류 파형 형태가 관여**한다. 보고서 1.1의 "전류 직류 성분 차이" 설명은 판정 기전으로는 틀린 강조다.
  - 반대 방향 방어 근거도 있다. **진동 진폭 특징 6개만 쓴 Mahalanobis도 AUROC 0.995**(평가 블록 경보율 0.27%, 고장 Recall 0.914). 진동 진폭의 5배 증가는 계측 경로 차이로 설명하기 어려운 크기다(단, 센서 재부착·감도 변경은 배제 불가).
- **보고서 반영 권고**: 1.2 품질 진단에 "두 파일의 수집 경로 차이" 행을 넣는다(진단표 신설). 1.5와 3.1의 교란 서술을 "전류 직류 성분"에서 "전류 양자화·파형 형태"로 바꾼다. 2단 진동 확인과 진동 진폭 단독 결과를 방어 논리로 묶는다. 이 단락은 **1장 데이터 진단의 차별점**이 된다.

## 7. 발표평가 예상 질문과 답변 (검토자 ③)

| 질문 | 답변 요지 |
|---|---|
| 결국 날짜를 탐지한 것 아닌가? | 1단은 그 위험이 크다. 두 파일은 전류 양자화부터 다르다. 그래서 빨강은 전류를 보지 않는 2단 확인을 요구한다. 진동 진폭만으로도 AUROC 0.995다. 진동 센서 감도·부착 변화까지는 배제하지 못한다 |
| 80분의 1은 일반적인가? | 평가 블록 값이다. 정상 전체로는 약 13분의 1, 블록별 4.5~80배. 운영은 블록별 범위로 계획한다 |
| 오경보 3건으로 FPR을 말할 수 있나? | 사건으로는 2건이다. 버스트 부트스트랩 95% 구간 0~0.28%, 시간당 상한 60건. 시범운영에서 확정한다 |
| 게이트를 M3가 이기도록 바꾼 것 아닌가? | 결과를 본 뒤 바꾼 것이 맞고, 원 기준이면 BL-0다. 다만 섭동 한도를 17.0~89.7%p 어디에 두어도 M3이고, 최악 증가 최소화로도 M3다 |
| Brier 0.0025면 확률 문제가 해결됐나? | 아니다. 이 기록 안에서 점수가 거의 완전히 갈린다는 뜻이다. 새 고장의 확률은 유병률 가정별 사후확률로 판단한다 |
| 빨강인데 보정 확률 0.003인 window는? | 보정 확률은 1단 점수만 반영한다. 빨강은 2단 확인과 연속 규칙의 결과이며 현장 절차는 센서 확인부터다 |
| 중부하 × 시작부 상호작용의 근거는? | 사건 1건이다(p=0.14). 가설로만 제시한다 |
| 시작부 미탐은 데이터 탓인가 규칙 탓인가? | 주로 규칙 탓이다. 첫 1초 미탐 47개 중 33개가 첫 2 window이고, 3번째 window부터는 Recall 0.894다 |
| 연속 3은 결과를 보고 고른 것 아닌가? | 계획서에 명시된 값이다. 시각으로 사전 고정을 증명하지는 못한다. 연속 1~5 전체를 공개했다 |
| 블록 4는 정말 처음 본 데이터인가? | 동결 구성의 적합·보정에는 쓰지 않았다. 선정 CV와 gate3 한도에는 쓰였다 |
